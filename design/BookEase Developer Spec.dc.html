03 — ARCHITECTURE & FOLDER STRUCTURE

How to lay out the project

Three independent repos (or a monorepo with three packages) sharing the same API contract and design tokens.

AAngular frontendbookease-web/
src/app/
├─ core/                 # singletons: api, auth, interceptors, guards
│  ├─ services/          services.service.ts, bookings.service.ts, auth.service.ts
│  ├─ interceptors/      auth.interceptor.ts, error.interceptor.ts
│  └─ guards/            admin.guard.ts
├─ shared/               # reusable UI + models + pipes
│  ├─ components/        button, service-card, status-badge, data-table,
│  │                     input-field, search-bar, filter-chip, empty-state…
│  ├─ models/            service.model.ts, booking.model.ts, user.model.ts
│  └─ pipes/             money.pipe.ts, duration.pipe.ts
├─ features/
│  ├─ landing/           landing-page.component
│  ├─ services/          services-page, service-detail
│  ├─ booking/           booking-page, confirmation-page
│  └─ admin/             admin-layout, dashboard, bookings, services
├─ styles/               _tokens.scss (color/type/spacing), _base.scss
└─ app.routes.ts         # lazy-loaded feature routes
SSwiftUI iOS appBookEase/
BookEase/
├─ App/                  BookEaseApp.swift, RootTabView.swift

│  └─ Components/        PrimaryButton, ServiceRow, StatusBadge,

└─ Resources/            Assets.xcassets, Info.plist
NNode.js + Express backendbookease-api/
src/
├─ config/               env.ts, db.ts (pg Pool)

├─ modules/

DBPostgreSQL tables
users
id uuid PK · full_name · email uniq · phone · password_hash · role (customer|staff|owner) · created_at
categories
id uuid PK · name · slug uniq · sort_order
services
id uuid PK · name · description · price_cents int · duration_min int · category_id FK · image_url · rating · active bool · created_at
coaches
id uuid PK · user_id FK · bio · specialties text[] · avatar_url
availability
id uuid PK · coach_id FK · service_id FK · starts_at timestamptz · is_booked bool
bookings
id uuid PK · ref (BK-xxxxx) · user_id FK · service_id FK · coach_id FK · starts_at · status enum · notes · price_cents · created_at
payments
id uuid PK · booking_id FK · amount_cents · provider · status · created_at
reviews
id uuid PK · booking_id FK · service_id FK · rating int · comment · created_at
