04 — UX FLOW & BUILD NOTES

From design to code

The flows are intentionally linear and easy to implement in Angular and SwiftUI on a shared API.

CUSTOMER FLOW
Home→ Services→ Detail→ Booking→ Confirmation→ History
ADMIN FLOW
Dashboard→ Booking management→ Service management→ Add / edit service
Desktop · ≥1024px
Full multi-column layouts, persistent admin sidebar, 3-col service grids, side-by-side booking form + summary.
Tablet · 768–1023px
2-col grids, collapsible sidebar, summary stacks under the form, condensed tables with horizontal scroll.
Mobile · <768px
Single column, bottom tab bar, sticky CTAs, cards replace tables — matching the native iOS layouts.
